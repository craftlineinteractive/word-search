# Asset Manifest & Licensing Provenance

All image assets integrated into this project are permanently stored in `assets/game_art/`. They have been selected and organized from Kenney Game Assets, released under the **Creative Commons CC0 1.0 Universal (Public Domain Dedication)** license.

The temporary source folder `assets/elements/` is NOT referenced anywhere in the runtime codebase or configuration and can be safely deleted without impacting the game.
